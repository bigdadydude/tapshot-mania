# 都市背景贴图交付规格

所有尺寸均为源图像的准确像素尺寸（宽 × 高），以 390 × 844 游戏画面为参考，按约 4 倍清晰度制作。屏幕适配时各层完整拉伸到其目标区域，不裁切。由于车道位置随屏幕高度调整，源图像高度取整；不要将源像素尺寸当作固定的屏幕像素尺寸。

文件放在本目录。在 `src/game/city-art.ts` 的 `CITY_ART` 中将对应的 `null` 改为 `/game/scenes/city/文件名.png` 即可启用。未配置或未加载成功的层保持现有程序绘制，不会显示空白。不要把辅助线烘焙进最终图片。

- `sky.png`：**1560 × 2584**，不透明。覆盖整个背景区域，不画云、建筑、高架、立柱或道路。动态云单独复用街头地图已有素材。
- `buildings.png`：**1560 × 2584**，透明 PNG。整组高楼，底部落在图片最下边。楼外及楼间可见天空的部分必须透明；不要烘焙天空、云、桥或车。保持较低对比度。
- `windows.png`（玻璃图，可选）：**1560 × 2584**，透明 PNG，与 buildings.png 逐像素对齐，只保留需要发光的玻璃，其他位置完全透明。玻璃可用白色或任意颜色；程序读取透明度并统一染成柔和暖色，半透明玻璃会发出更弱的光。不要提供不透明黑底蒙版，否则整个矩形都会发光。入夜时整体渐亮，最高不透明度限制为 38%。不提供此图时，替换后的高楼不会叠加旧楼的窗灯。
- `road.png`：**1560 × 794**，不透明。完整横向马路，含车道线、近侧路缘和人行道；不画汽车、立柱或高楼。图片上边缘是地面汽车轮胎基线。保持横向交通方向，不要画成朝远处延伸的纵向道路。
- `bridge.png`：**1560 × 116**，透明 PNG。只有高架侧面的桥面、梁体；不画立柱或汽车。**上边缘就是高架汽车轮胎基线**，不要在上方留透明边，否则车会悬空。
- `pillar.png`：**144 × 1150**，透明 PNG。单根立柱，包含顶部柱帽，左右居中。顶端接桥梁底面，底端接地面；建议柱身占中间一半宽度，柱帽可占满宽度。同一张图复用两次，不需绘制两根。

## 图层顺序（从后向前）

天空 → 街头动态云 → 高楼 → 窗灯 → 马路 → 立柱 → 高架梁体 → 汽车 → 篮球和游戏 UI。

## 位置与单点透视对齐

以 390 × 844 参考画面为例，左上角为 (0,0)：

- 背景（天空/楼/窗灯）：x=0，y=0，宽390，高645.66。
- 马路：x=0，y=645.66，宽390，高198.34。
- 高架：x=0，y=329.2866，宽390，高29。
- 立柱：中心 x=70.2、319.8；顶端 y=358.2866，底端 y=645.66；每根外框宽36，高287.3734。
- 统一透视消失点：画面 (195,355.113)，即 road.png 源坐标约 **(780,-1163.10)**。消失点在马路图片上方；纵深方向边线向此点延长，横向车道线保持水平。

不同画幅会按游戏布局缩放背景高度、路面深度和柱高；桥厚与柱宽按画面宽度同比例缩放。所有贴图只替换视觉，不改变车辆碰撞、车道或篮球落地点。

## 制作模板

`templates/` 中的同名 PNG 为准确尺寸的空白透明画布，供绘图软件导入使用；它们不参与游戏渲染。天空和马路最终需画满并导出不透明图，其余四张保留透明背景。高楼图和玻璃图应在同一绘图文档中建立两个图层，导出时保留完整画布，不要“裁切透明像素”或分别缩放。

天空、高楼和玻璃三张图保持相同左上角原点及完整尺寸。高架和立柱为独立部件，不能烘焙进高楼图。收到最终贴图后，再将 `CITY_ART` 对应入口设置为本目录图片的 URL；目前保留原有程序画面作回退。

## 昼夜

保持都市现有昼夜循环。天空、楼体、道路、桥和立柱贴图会随夜色降低亮度；窗灯通过独立透明图渐亮。请交付正常日间亮度贴图，避免自带强光、光晕或把窗灯烘焙在楼体上。
