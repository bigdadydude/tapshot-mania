# 高速列车顶地图 — 开发档案

状态：**第一步已实现**。第二步（惯性）、第三步（横杆 + 鸟群）、第四步（隧道）**未实现**。

## 概述

在高速列车顶部进行投篮的新地图。核心体验是「在移动的列车上投篮」，通过列车速度变化、障碍物和隧道制造节奏与挑战。

## 已确认的设计决策

### 速度变化

- 触发方式：固定节奏循环（加速 → 匀速 → 减速 → 再加速……）
- 具体时长第一版用下面的常量，方便以后调

### 障碍物惩罚 — 未实现

- 横杆：碰到后球被撞飞（轨迹被强制改变）
- 鸟群：随机出现，碰到后球被抢走 1–2 秒（期间无法正常投篮）

### 隧道 — 未实现

- 频率暂不定
- 含进隧道前狭窄洞口、隧道内顶端变暗 + 起伏躲避、出隧道镜头炫光

### 背景

- 最底层复用街头的天空图和云朵，不另画一整块背景板
- 其上叠三层景别物体：远景、中景、近景。每层只有物体，没有自己的底色、天空带或山丘底板，空隙透出天空和云
- 三层物体的脚对齐同一条地平线（车顶那条线）。以车顶到画面顶的竖直跨度为 H：电线杆约 H×1/4，山脉高度随机、大致约 H×1/2，树林不超过 H×1/3
- 山体偏宽，不是细锥；颜色从下边的蓝灰过渡到上边的白
- 云朵用街头那套，随机画在山的后面或前面，但一定在树林后面，被树盖住
- 三层物体向后滚动（近景最快 → 远景最慢），速度与当前列车速度挂钩
- 倍率：近景 1.0 / 中景 0.45 / 远景 0.15
- 正式美术未做。占位是：远景宽大的蓝灰到白的山，中景连成片的树林，近景电线杆

## 开发阶段

### 第一步 · 在移动的列车上投篮 — 已实现

目标：做出「在移动的列车上投篮」的基础感觉。

内容：

1. 列车速度状态机：维护 `trainSpeed`；按固定节奏切换加速 / 匀速 / 减速；背景滚动速度跟随 `trainSpeed`
2. 三层视差物体：远景 / 中景 / 近景各自偏移，画在透明层上；可平铺循环滚动
3. 投篮：完全复用现有投篮物理。地面是一节车厢的侧视图（画幅窄，只露出一部分），玩家站在这节车厢顶上。车厢不滚动。车厢上方先是街头那套天空和云，再叠三层物体，各自向后滚动

验收：

- 三层背景以不同速度向后滚动（景物向左）
- 加速时背景明显变快，减速时变慢
- 投篮手感与普通场景一致
- 滚动循环无缝

本版常量（`src/game/train-bg.ts`，直接改这些数即可）：

| 常量 | 值 | 含义 |
|------|----|------|
| `TRAIN_ACCEL_SEC` | 4 | 加速阶段秒数，速度从慢线性升到快 |
| `TRAIN_CRUISE_SEC` | 5 | 匀速阶段秒数，保持最快 |
| `TRAIN_DECEL_SEC` | 4 | 减速阶段秒数，速度从快线性降到慢 |
| `TRAIN_SPEED_MIN` | 90 | 近景像素/秒，减速结束、加速开始 |
| `TRAIN_SPEED_MAX` | 540 | 近景像素/秒，加速结束与整个匀速阶段 |
| `TRAIN_PARALLAX` | 1 / 0.45 / 0.15 | 近景 / 中景 / 远景相对 `trainSpeed` 的倍率 |

一整圈 13 秒。速度牌画在车厢白色车身上、蓝窗带上方（加速 / 匀速 / 减速 + 格数），只表示当前阶段，不改变物理。

怎么辨认这一步画对了：以车顶到画面顶为 H，电线杆大约四分之一高，树林不超过三分之一高，山大约一半高而且又宽又大、下蓝灰上白。云在山前或山后，但一定被树林挡住。电线杆滚得最快，山最慢。画面下方仍是一节车厢的侧面（车窗、车门、轮子，左右会被画面裁掉），车顶不动。

实现落点：

- `src/game/train-bg.ts`：速度状态、三层物体偏移、占位物体
- 天空和云走街头同一套绘制（`drawOpenSky`）。`ScenePack` 字段未改。`train` 场景复用街头的资源壳，不画街头墙和地面
- 标题画面场景栏与开发者模式「当前场景」都可选「列车」，和街头 / 监狱 / 都市同一条切换路径

### 第二步 · 惯性 — 未实现

球随列车加减速产生惯性。本步不做。第一步的投篮物理与普通场景一致，球不会被车速带动。

### 第三步 · 横杆与鸟群 — 未实现

- 鸟群：随机出现，碰到后球被抢走 1–2 秒（期间无法正常投篮）

### 第四步 · 隧道 — 未实现

频率暂不定。含进隧道前狭窄洞口、隧道内顶端变暗 + 起伏躲避、出隧道镜头炫光。

## 技术备注

- 自定义 Web 引擎（React + TypeScript + Canvas）
- 现有 `scenes.ts` 仍是静态场景包。列车滚动不塞进 `ScenePack`，由 `train-bg.ts` 单独推进
- 暂停时速度循环停下；时间倒流技能期间背景也不滚，避免和倒放打架
- 进入列车场景时循环从「加速、最慢」重新开始

## 怎么试

1. 标题画面点「列车」，再点「开始」。下方应是车厢侧面。上方先看到天空和云，物体叠在云前面，空隙里仍是那片天空。
2. 看车厢上的速度牌：加速时格数变满、电线杆明显加快；匀速保持快；减速变慢。山从同一条地平线起，大约到画面中部，始终最慢。树林比山矮，树顶不超过 H 的三分之一。云不会盖住树。
3. 开发者沙盒（标题连点「投球」八下）→ 场景栏 →「列车」，同一套背景。
