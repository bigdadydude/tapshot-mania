# 骇客球：三段技能与代码世界

更新：2026-11-14。PR30 分支规则，尚未合并 main。本说明替代此前红蓝药丸、多筐定住、延时滴分和长按留筐方案。

## 共通操作

- 点按立即起跳；按住超过 **0.22 秒**截停并耗气，每整段耗时 **0.32 秒**。从按下到耗完三段约 **1.18 秒**，旧版为 1.65 秒。
- 每 5 次实体进球充满一段，最多三段；每段续满有对应青、绿、紫色光晕。
- 松手按扣完的整段发动技能；没扣完的段返还，不满三段最多发动二段。不足一段时返还并停球 0.2 秒。
- 现实中超过 3 秒未进球，每秒流失 1 点气；代码世界不自然衰减。
- 两个世界均正常即时计分，不再有延时滴分或为了等分而留筐。

## 技能

| 段数 | 现实世界 | 代码世界 |
| --- | --- | --- |
| 一段 | 飞天，以移动箭头选择落点；点击确认，3 秒未点自动落下；成功进球带深水 | 同样飞天选落点；每成功一次，之后每次实体进球额外 +1 连击，可叠加 |
| 二段 | 锁筐跳投，成功进球带深水且本次总分 ×2 | 同左 |
| 三段 | 锁筐跳投，**真实入网时**才切入代码世界 | 立即撤离并跳投，将本轮代码世界已赚取的连击加成带回现实 |

- 一段奖励绑定本次技能实体进球；发动但没进球不获得，分身不能代领。本次先使用原有加成结算，再给后续进球增加一层。
- 二段翻倍仅本次技能进球有效，不翻倍总分，不留给失误后的普通投篮或分身。
- 现实三段飞行时仍是现实；未入网不转场，三段不额外赠送深水奖励。
- 代码世界气满三段时保留黑电话作为快捷撤离，效果与三段撤离相同。

## 连击加成与带回

- 区分「已带回」和「本轮代码世界新赚」两部分。
- 新赚部分在撤离前只作用于代码世界。三段撤离时一次性转成已带回；多次进出只带回新增部分，不重复转存。
- 已带回加成在本局两个世界均有效；普通进球原有 +1 连击仍保留。例如已有 2 层加成时，普通实体进球增加 3 连击。
- 加成不会因为落地、断连而清除，但重开/新局清零，不跨局保存。
- HUD 显示当前每球额外连击；现实显示已带回，代码世界显示时钟惩罚。

## 代码世界代价

- 投篮钟时长为正常的 **94%**；进入时按比例缩短当前剩余时间，退出时恢复比例，不额外补满。
- 普通投篮钟原有衰减仍存在，但代码世界 0.94 倍只施加一层，不随每次续钟重复累乘。
- 一分钟模式不因进球续钟；进入/退出只按比例转换当前剩余时间。
- 暂停不走时间，回溯一并恢复世界、气、技能和连击加成。

## 保留内容

代码雨与绿色视觉、普通左右轮换篮筐、近处鸟/车自动清除（每个获得一层可带回的每球额外 +1 连击）、各种球融合和原有模式规则继续存在。没有恢复红蓝药丸、随机定筐或多筐奖励。

## 验收重点

1. 普通代码进球一次性到账，与现实同一计分流程。
2. 一段成功/失误、分身不代领、断连仍保留层数、多次带回不重复。
3. 二段单次翻倍，失误后不污染下一球。
4. 现实三段入网前不变绿，进球时只切换一次。
5. 代码三段及电话撤离后加成可在现实用，当前钟恢复且不重置。
6. 重开清零、回溯克隆恢复，暂停不衰减动画或计时。

## 跳投锁定与击落（2026-11-14 补充）

- 发动任意段跳投后，禁止点击起跳或再发动技能；一段顶部箭头仍可点击确认落点（不产生起跳）。
- 下落触碰任意飞行物直接击落，包括鸟、冻结鸟、普通与精英弹体，篮球不因此被撞飞。每个对象只结算一次。
- 下落触碰篮架任意部位（板、支撑、连接件、圈、网）或地面才恢复操作。击落飞行物本身不解锁，入网计分本身也不提前解锁。
- 代码世界每次击落获得与一段相同的一层「后续每球额外 +1 连击」，不再直接给当前连击 +1；三段撤离统一带回。现实跳投也能击落，但不赚代码加成。
- 已有代码世界清车保留，奖励也改为上述可带回层数。
