# 投球 · 一页介绍

**点一下，球就跳。把球送进左右轮换的篮筐。**

竖屏浏览器投篮。没有摇杆、没有准星，只有点击时机、连击和篮筐换边。空心、擦板、压哨会加分并打出标签；连击一断，节奏立刻变。

## 三种节奏

- **经典**：衰减投篮钟。越投时钟越紧，压哨时空中球还能搏绝杀。
- **1分钟**：首球后固定 60 秒，纯冲高分。冠军球不能用。
- **肉鸽**：五关目标分，过关换钱进商店，通关后可以无限续摊。开局还能把两颗球的技能融在一起。

## 手感

点按（或空格 / ↑）起跳；球还在空中可以再点一次加力。标题页左右滑动选球，也可以开随机。燃烧、冰冻、玻璃、忍者、反重力、弹力……每颗球改的是物理和规则，不是皮肤。

## 肉鸽现在打什么

商店目录已经从策划表进游戏，道具 / 饰品均可买到（过关后每次最多 2+2 个货架，按稀有度抽）。完整条目见 [rogue-shop-catalog.md](rogue-shop-catalog.md)。
