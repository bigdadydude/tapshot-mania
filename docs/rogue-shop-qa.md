# 肉鸽商店目录验收清单

对照来源（未臆造效果）：

- 产品目录：`docs/rogue-shop-catalog.md` / `docs/rogue-shop-catalog.csv`（43 条，全部「启用」）
- 运行时目录：`src/game/rogue-catalog.ts`（商店文案 / 价格 / 数值的实际来源）
- 规则与购买：`src/game/rogue.ts`
- 局内结算：`src/game/engine.ts`
- 球种融合：`src/game/balls.ts` `effectiveBall()`

判定：

| 标记 | 含义 |
|------|------|
| **通过** | 有实现，且与目录效果描述一致（允许目录未写明的内部数值） |
| **需调参** | 有实现，但叠层 / 触发条件 / 价格稀有度 / 球种过滤与目录或手感明显不符 |
| **未实现** | 目录有、代码无对应结算 |
| **文案不清** | 有实现，但目录没写清数值或机制，玩家无法从商店描述判断买什么 |
| **建议砍掉** | 代码有钩子，但战役局内几乎触发不到，或与现有系统冲突到不如去掉 |

**汇总：通过 21 / 需调参 14 / 文案不清 7 / 未实现 0 / 建议砍掉 1**（共 43）

商店货源与目录无缺项、无多出的启用商品。代码里有未挂商品的 `clutch` 标签槽，目前没有任何饰品用它。

## 0. 目录文件 vs 代码（先对齐表）

商店 UI 读的是 `rogue-catalog.ts`，不是 md/csv。下列不一致会直接导致「表上写的」和「店里看到的」不同：

| 点 | 目录 md/csv | `rogue-catalog.ts` |
|----|-------------|-------------------|
| `HeroMoment` 名称 | 绝杀**绝杀**时刻（疑似笔误） | 绝杀时刻 |
| `streakSave` 可叠加 | 是，上限 `-` | `stackable: false`；购买硬上限 **3** 次 |
| `funsize` 描述 | 「篮球缩小 / 缩小为弹力球大小」 | 「篮球半径缩小为当前一半」 |
| 可叠加上限空白 / `-` | 产品表像无限 | 代码默认 **5 层**（`DEFAULT_STACK`） |
| `rematch` | 上限 2 | 上限 2，与 `REVIVE_CAP` 一致 |

金币来源（决定价格是否合理）：过关金 = `目标/10`（200→20）+ 本关最高连击 + 超出目标的分数。战役 5 关、关卡目标固定 200。传说 50–55 金通常要第二关以后才买得起，这是经济底线，不是 bug。

## 5. 球种融合（目录外，但会改商店与效果）

`effectiveBall(主球, 副球)`：外观 / 物理 / 换边方式跟主球；技能 flag 做 OR；半径相乘。

和商店的交叉：

1. **商店过滤只用主球 id**（`openRogueShop(run, ballId)`）。`startearlier` / `safepackage` 不认「融合里有经典/玻璃」。
2. **黑洞 + 反重力**（主或副）：开局 4s 洞内投篮分为 0，引力弹弓空转。
3. **分身术 + 忍者球**：同一套残影槽，分身术开着时忍者阈值分身不出现。
4. **热火饮料 + 非燃烧**：没有烈焰加分（见上）。
5. **儿童装 + 弹力球**：半径再 ×0.5。
6. 监狱球 `playable: false`，融合选不了。

融合本身已实现，不计入 43 条商品判定。

## 6. 价格 / 稀有度（只标偏离大的）

战役过关大约 20+ 连击金，普通 10、稀有 15–30、史诗 35–45、传说 50–55，档位大体能买。问题在**同效果不同档**：

| 观察 | 建议 |
|------|------|
| 穿针暴击 普通 10 / +5 vs 幸运暴击 稀有 15 / +5 | 穿针或涨价或降到 +2～3，或改稀有 |
| 深水暴击 普通 20 / +10 | 改稀有或降到 +3～5 |
| 空心货币 稀有 20 / 金+1 vs 马桶币 普通 10 / 金+1 | 可保留（空心更常见） |
| 引力弹弓 55 且叠层 6 倍、9 倍 | 叠层改为加性或层数只加时长/次数 |
| 缓慢计时 45 可叠加但不叠效果 | 取消可叠，或每层再缓一档 |
| 镇静剂 40 | 见「建议砍掉」 |
| 传说 50–55 vs 关卡金 ~20 | 可保留为二关以后货；若希望第一店出现传说，降到 ~35 或给首关额外金 |

可叠加默认 5 层、目录写无限：产品要二选一写进表。

## 7. 建议的后续（本 PR 只交清单，不改数值）

1. 把 md/csv 与 `rogue-catalog.ts` 三处名称、叠加、描述对齐。  
2. 商店描述补数值：±8% 跳、+12% 重力、烈焰=+3 分且需燃烧、迪克云=14s、安全包装=任意一次玻璃受伤。  
3. `startearlier` / `safepackage` 过滤改成看 `effectiveBall`（有经典/玻璃技能即出现）。  
4. 分身术 vs 忍者、黑洞 vs 反重力：或写进描述，或改成可共存。  
5. 镇静剂：把「50 记后才动态」降到战役能碰到，或下架。  
6. `alice`：缩放时不要丢掉 `inner`；若「篮架不变」是需求，gap 不要跟 inner 走。
