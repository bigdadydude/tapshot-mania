# 蓝图（Blueprint）

阶段 1 已实现。阶段 2、3、4、5 未实现。

玩法仍是原来的点击起跳。本图只加图纸背景和会挡路的网格方块，不改投篮手感。

## 外观

- 背景：纯蓝色，加白色网格线。
- 地面：白色网格，单点透视，近大远小。消失点在地面线中点，靠近画面底边的格子更大。
- 篮架：篮板、支架、篮圈、篮网都是纯白色。热度不会把它熏黑。

## 机制

### 1. 网格凸出障碍（阶段 1，已实现）

网格方块随机凸出。方块底部有阴影，侧面和顶面错开一点，用来表现厚度。

凸出的方块是墙：球撞上去会弹开，较低的方块可以用普通一跳越过去。左右篮筐所在的竖向通道、贴地的落点、以及画面上方一条高弧通道都不放方块，避免把篮筐整个堵死。

动态方块只在自己的格子里伸缩，格子坐标不动。缩到几乎贴平时不再挡球，伸出后恢复成墙。同一局里已经出现的方块不会挪到别的格子。

对局进行得越久，方块越多，其中动态方块也越多。数量有上限。本阶段没有方块之间的红色激光。

重新进入蓝图、或回到标题，会重新抽一块图纸。点开始之后，这一局的格子保持不变，只是从零重新计算出现进程。时间倒流会连同图纸、进程和伸缩相位一起还原。

### 2. 激光惩罚（阶段 2，未实现）

篮球穿过激光时播放「被切成两半」特效，然后进入短暂惩罚。惩罚多样，且不是永久的：切割、爆炸、变小、物理参数改变、变成鸟等。具体效果需要调试。

### 3. 顶部干扰体（阶段 3–4，未实现）

左右两角降下发射器，同时最多 2 个。

- 黄色球体速度不快，在界面内无限弹射，用来干扰。
- 银色球体像无人机，持续追踪篮球。

两者都可以被击落。阶段 3 只做发射器和黄色弹射球，阶段 4 再做银色追踪球。

### 4. 图纸系统（阶段 5，未实现）

地图随机发放设计图纸。完成图纸任务可以制作零件，难度越高，零件威力越强。之后再接入肉鸽。任务内容由用户设计。

## 开发顺序

1. 背景 + 网格凸出（含动态伸缩方块）——已实现
2. 基础激光 + 调试惩罚——未实现
3. 升降发射器 + 黄色弹射球——未实现
4. 银色追踪球——未实现
5. 图纸系统——未实现

## 阶段 1 可调常数

都在 `src/game/blueprint.ts` 顶部。

| 常数 | 默认 | 作用 |
| --- | --- | --- |
| `BLUEPRINT_BLOCK_SIZE` | 44 | 方块边长。按画面宽 390 缩放，背景网格用同一间距 |
| `BLUEPRINT_MAX_COUNT` | 6 | 同时存在的凸出方块上限 |
| `BLUEPRINT_RAMP_PACE` | 10 | 每多出现一个方块所需的对局秒数 |
| `BLUEPRINT_EXTEND_PERIOD` | 2.6 | 动态方块伸出再缩回一圈的秒数 |
| `BLUEPRINT_START_COUNT` | 3 | 开局就在场上的方块数。前两格是固定墙，从第三格起是动态方块 |
| `BLUEPRINT_HIT_EXTEND` | 0.12 | 缩到这个比例以下就不再碰撞 |
| `BLUEPRINT_STAGGER` | 0.37 | 相邻动态方块的相位差，占一个伸缩周期的比例 |
| `BLUEPRINT_BOUNCE` | 1.65 | 撞墙分离系数，法向速度大约弹回 0.65 |

开局 3 个方块里有 1 个在伸缩。之后每 10 秒多一个，新增的都是动态方块，最多 6 个。安全格子不够时，实际数量会少于上限。

## 怎么试

1. 在标题页的场景条点「蓝图」，再开始。
2. 开发者模式里，当前场景同样可以切到「蓝图」。
3. 看蓝色网格和透视地面，篮架是白的。
4. 把球投到凸出的方块上，球会弹开。
5. 较低的方块可以一跳越过去；左右两边通往篮筐的通道是空的。
6. 多打一会儿，方块变多，动态方块在原地一伸一缩。
