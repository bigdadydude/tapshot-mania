# 蓝图（Blueprint）地图 — 开发档案

档案日期：2026-10-19。

实现状态：第一步已实现（本分支）。第二步、第三步、第四步、第五步未实现。

## 概述
Tap Shot Mania 新场景「蓝图」。纯蓝网格风格，强调环境干扰与后期零件成长。视觉与现有街头/监狱场景明显区分。

## 外观
- 背景：纯蓝色 + 白色网格线
- 地面：白色网格按单点透视绘制（近大远小）
- 篮架：纯白色

## 已确认机制

### 1. 网格凸出障碍

**实现状态：** 本分支已完成背景、凸出墙体和原地伸缩。指挥官已确认下面的生成规则，替换原先的「开局 3 个、每 10 秒多一个、最多 6 个、固定伸缩周期」。每一批都会缩回，没有永久凸出。方块之间的红色激光属于第二步，未实现。

#### 选位

- 候选格二选一：随机空闲格，或投篮必经路（篮球到当前篮筐的合理路径附近的格子）。
- 不得与篮架、篮筐通道重叠，沿用现有左右走廊禁区。
- 篮球周围 **2 格半径**内不生成，避免卡死或穿模。半径按格子边长计：格子中心到球心的距离 ≤ `2 × 格边长` 的格子排除。

#### 时长

- 凸出时长从 **1 秒**起步。
- **每进一球**，可选时长的右端增加 **0.2 秒**。
- 上限 **6 秒**。
- 无永久凸出：每一批都会缩回。
- 当前这一批的时长，在开批时从区间 `[1, min(6, 1 + 0.2 × 进球数)]` 秒里随机取一个数。进球数为 0 时区间是 `[1, 1]`，也就是 1 秒。三个常数固定为起步 1、每球 +0.2、封顶 6。
- 时长在这一批开始时定死。本批用这段时间完成一次伸出再缩回（周期中点完全凸出，周期结束回到贴平）。中途进球不改本批，下一批才用新的进球数。

#### 数量与形状

- 同时凸出的格子总数 **≤ 10**。
- 形状：直线排、斜线、Z、L、S、U、V、C，以及同类的旋转、镜像。生成后裁到合法格上，裁完仍然不超过 10。
- 手感：**单格**可以绕过或跳过，不会把球卡死；**整排**横在路上时才挡得住球。

#### 动态与视觉

- 只伸缩，位置不移动。
- 凸起后整格是墙。
- 填色贴白网格线，不画侧面。越凸越亮。只从底边投一条直影。阴影落在下方另一个凸出格上时，重叠的那一段随下方凸出程度减淡，下方完全凸出时重叠区透明度为 0。消失点在墙地交线上方。

### 2. 激光惩罚

**实现状态：** 未实现。

- 篮球穿过激光：播放「被切成两半」特效，随后进入短暂惩罚
- 惩罚多样且**非永久**：切割、爆炸、变小、物理参数改变、变成鸟等
- 具体效果与时长需在实现阶段调试

### 3. 顶部干扰体

**实现状态：** 未实现。黄色弹射球为第三步，银色追踪球为第四步。

- 左右两角降下发射器
- 同时最多存在 2 个干扰体
- **黄色球体**：速度不快，在游戏界面内无限弹射，干扰进球路线
- **银色球体**：持续追踪玩家篮球（无人机式）
- 两者均可被击落

### 4. 图纸系统（最后实现）

**实现状态：** 未实现（第五步）。

- 地图随机发放设计图纸

- 任务难度越高，零件威力越强
- 后续接入肉鸽模式
- 任务内容由策划设计

## 第一步详细要求（当前优先）
- 纯蓝背景 + 白色网格（地面单点透视）
- 网格方块可随机凸出，底部阴影
- 凸出方块作为墙体弹开篮球，可跳过
- 支持动态方块伸缩（位置不变）
- 篮架纯白
- 可独立运行与测试，不依赖后续激光/干扰体

## 本版实现

第一步的网格和伸缩在独立模块 `src/game/blueprint.ts`，没有写进静态场景包。标题页点「蓝图」再开始即可单独验收。常数都在该文件顶部。

绘制：

- 墙面网格的底边贴在墙地交线上。地面纵线从这些竖线接下去，交线处的间距和墙面格子相同。
- 消失点在交线上方，不在交线上。地面第一格和墙面格子一样高，越靠近画面底边格子越大（`BLUEPRINT_FLOOR_SPREAD`）。
- 凸出方块的填色边和白色网格线重合，不留缝，也不另画侧面。凸得越高，格子越亮。只从底边向下投一条直边阴影，靠近底边更暗，末端变淡，凸得越高影子越长。若这段阴影落在下方另一个凸出方块上，重叠的那一段随下方凸出程度减淡，下方完全凸出时重叠区透明度为 0。没有贴边接触影，也没有永远凸着的格子。一旦凸出，整格就是墙（不再从中心缩小）。球撞上会弹开并滑离格子，不会黏在顶上；从下方跳起时也不会被底边折返。单格可以绕开或跳过；一整排横在投篮路上时，球才会被挡住。

每一批只生成一个形状：直线排、斜线、Z、L、S、U、V、C 之一，可旋转、可镜像。锚点要么是随机空闲格，要么落在投篮必经路附近（球到当前篮筐的弧线邻近格）。再裁掉走廊禁区、篮筐通道，以及篮球 2 格半径内的格子。裁完的格数不超过 10；合法格不够时，这一批可以短于形状原样，甚至暂时不凸出。

这一批的伸缩周期，等于开批时从 `[1, min(6, 1 + 0.2 × 进球数)]` 秒抽到的时长。同一批一起伸缩，不再按格子错相。周期中点完全凸出，周期结束回到贴平，然后换下一批。进球数读当前对局；中途进球不改本批时长。不再使用开局固定个数，也不再按对局秒数往上加方块。

| 常数 | 默认 | 作用 |
| --- | --- | --- |
| `BLUEPRINT_BLOCK_SIZE` | 44 | 方块边长。按画面宽 390 缩放，背景网格用同一间距 |
| `BLUEPRINT_MAX_COUNT` | 10 | 同时凸出的格子上限。原为 6 |
| `BLUEPRINT_EXTEND_MIN` | 1 | 凸出时长下限，秒。进球数为 0 时整段就是 1 秒 |
| `BLUEPRINT_EXTEND_PER_GOAL` | 0.2 | 每进一球，时长区间右端增加的秒数 |
| `BLUEPRINT_EXTEND_CAP` | 6 | 凸出时长上限，秒。区间右端为 `min(6, 1 + 0.2 × 进球数)` |
| `BLUEPRINT_BALL_CLEAR` | 2 | 篮球周围禁生成的半径，按格计。格子中心到球心 ≤ `2 × 格边长` 则不放 |
| `BLUEPRINT_RAMP_PACE` | 已废弃 | 原为每 10 秒多一个方块。时间爬坡已删除，难度改由凸出时长随进球变长 |
| `BLUEPRINT_EXTEND_PERIOD` | 已废弃 | 原为固定 2.6 秒伸缩周期。改由 `BLUEPRINT_EXTEND_MIN` / `PER_GOAL` / `CAP` 决定 |
| `BLUEPRINT_START_COUNT` | 已废弃 | 原为开局固定 3 个。改为按形状成批生成，不再预放固定个数 |
| `BLUEPRINT_STAGGER` | 已废弃 | 原为相邻格子的相位差。同一批一起伸缩，不再错相 |
| `BLUEPRINT_HIT_EXTEND` | 0.12 | 缩到这个比例以下就不再碰撞 |
| `BLUEPRINT_BOUNCE` | 1.65 | 撞墙分离系数，法向速度大约弹回 0.65 |
| `BLUEPRINT_BOUNCE_CLEAR` | 0.16 | 落在格子顶上时至少弹起的高度，按球半径计。太小会黏住，太大会弹进上一格 |
| `BLUEPRINT_FLOOR_SPREAD` | 2 | 画面底边的地面格子相对交线处放大的倍数。消失点因此在交线上方 |
| `BLUEPRINT_MAX_LIGHTNESS` | 0.18 | 完全凸出时浅色罩的不透明度。越大越发白，仍比平格子亮 |

测试：`src/game/blueprint.test.ts`。覆盖同时凸出不超过 10、时长公式、形状裁剪后的上限，以及走廊和篮球 2 格禁区。
