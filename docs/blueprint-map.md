# 蓝图（Blueprint）地图 — 开发档案

档案日期：2026-10-19。

实现状态：第一步已实现（本分支）。第二步、第三步、第四步、第五步未实现。

## 概述
Tap Shot Mania 新场景「蓝图」。纯蓝网格风格，强调环境干扰与后期零件成长。视觉与现有街头/监狱场景明显区分。

## 外观
- 背景：纯蓝色 + 白色网格线
- 地面：白色网格按单点透视绘制（近大远小）
- 篮架：纯白色

## 已确认机制

### 1. 网格凸出障碍

**实现状态：** 本分支已完成背景、凸出墙体和原地伸缩。方块之间的红色激光属于第二步，未实现。

- 网格方块随机凸出，底部加阴影体现立体感
- 凸出方块 = 墙体：球会被弹开，玩家可以跳过
- 动态方块：仅做伸缩（位置固定不移动）
- 随游戏进程出现：多个方块、动态伸缩方块、方块之间的红色激光

### 2. 激光惩罚

**实现状态：** 未实现。

- 篮球穿过激光：播放「被切成两半」特效，随后进入短暂惩罚
- 惩罚多样且**非永久**：切割、爆炸、变小、物理参数改变、变成鸟等
- 具体效果与时长需在实现阶段调试

### 3. 顶部干扰体

**实现状态：** 未实现。黄色弹射球为第三步，银色追踪球为第四步。

- 左右两角降下发射器
- 同时最多存在 2 个干扰体
- **黄色球体**：速度不快，在游戏界面内无限弹射，干扰进球路线
- **银色球体**：持续追踪玩家篮球（无人机式）
- 两者均可被击落

### 4. 图纸系统（最后实现）

**实现状态：** 未实现（第五步）。

- 地图随机发放设计图纸
- 玩家完成图纸上的任务 → 制作零件
- 任务难度越高，零件威力越强
- 后续接入肉鸽模式
- 任务内容由策划设计

## 第一步详细要求（当前优先）
- 纯蓝背景 + 白色网格（地面单点透视）
- 网格方块可随机凸出，底部阴影
- 凸出方块作为墙体弹开篮球，可跳过
- 支持动态方块伸缩（位置不变）
- 篮架纯白
- 可独立运行与测试，不依赖后续激光/干扰体

## 本版实现

第一步的网格和伸缩在独立模块 `src/game/blueprint.ts`，没有写进静态场景包。标题页点「蓝图」再开始即可单独验收。常数都在该文件顶部。

| 常数 | 默认 | 作用 |
| --- | --- | --- |
| `BLUEPRINT_BLOCK_SIZE` | 44 | 方块边长。按画面宽 390 缩放，背景网格用同一间距 |
| `BLUEPRINT_MAX_COUNT` | 6 | 同时存在的凸出方块上限 |
| `BLUEPRINT_RAMP_PACE` | 10 | 每多出现一个方块所需的对局秒数 |
| `BLUEPRINT_EXTEND_PERIOD` | 2.6 | 动态方块伸出再缩回一圈的秒数 |
| `BLUEPRINT_START_COUNT` | 3 | 开局就在场上的方块数。前两格是固定墙，从第三格起是动态方块 |
| `BLUEPRINT_HIT_EXTEND` | 0.12 | 缩到这个比例以下就不再碰撞 |
| `BLUEPRINT_STAGGER` | 0.37 | 相邻动态方块的相位差，占一个伸缩周期的比例 |
| `BLUEPRINT_BOUNCE` | 1.65 | 撞墙分离系数，法向速度大约弹回 0.65 |

开局 3 个方块里有 1 个在伸缩。之后每 10 秒多一个，新增的都是动态方块，最多 6 个。安全格子不够时，实际数量会少于上限。测试：`src/game/blueprint.test.ts`。
