# 投球（Tap Shot Mania）

**点击弹跳，把球投进左右轮换的篮筐。空心、擦板、压哨加分；三种节奏，一套手感。**

浏览器里的竖屏投篮游戏：点一下球就跳，篮筐在左右两侧来回换。没有瞄准圈、没有摇杆——节奏全在点击时机和连击。分数、最高纪录和上次选的球种存在本机浏览器里，不需要账号。

更短的一页介绍见 [docs/pitch.md](docs/pitch.md)。

## 三种模式

标题页三个按钮对应三种玩法。冠军球不能用于「1分钟」。

| 模式 | 界面名 | 节奏 |
|------|--------|------|
| **经典** `classic` | 衰减时钟 | 第一次进球后开约 **15 秒**投篮钟。之后每次进球会把时钟加满，但上限乘 **0.972** 逐渐变短（最短约 2.6 秒）。时间耗尽时，空中未落地的球仍可进筐算绝杀。 |
| **1分钟** `minute` | 固定时长 | 第一次进球后开始 **60 秒**倒计时，不因进球缩短或回满。拼单局高分。 |
| **肉鸽** `rogue` | 闯关商店 | 正式 **5 关**，每关目标 **200 分**，投篮钟与经典类似。过关结算金币、进商店；通关后可选无限模式。纪录是「最远到第几关」。 |

经典 / 1分钟看总分；肉鸽看闯关深度。三种纪录分开存。

## 怎么玩

**投篮（点）**

- 点按场地（触控或鼠标左键），球朝当前篮筐弹跳。
- 键盘：`空格` 或 `↑` 同样起跳。
- 这一球还在空中、尚未进筐或落地时，再点一次会重新给冲量（加力），**不会**因此断连击。
- 反重力球开黑洞期间，点击会把球朝篮筐方向拽过去。时间耗尽后一般不能再起跳；空中球仍可进筐（绝杀 +5）。肉鸽饰品「绝杀时刻」例外：绝杀窗里仍可操控篮球。

**选球（滑）**

- 标题页横向滑动 / 拖拽卡片选球种，也可点指示点。
- 最左边是 **随机球**：开局时从当前模式可用球种里抽一个（1分钟模式不会抽到冠军球）。

**其它**

- `Esc` 暂停。暂停菜单可重开、进设置、回标题；肉鸽局里还能手动用部分道具。
- 左右篮筐轮换；连击超时会掉段。特殊进球会打出标签：空心球、擦板球、刷马桶（篮筐磕三次以上）、幸运弹球（板上端）、穿针引线（自下而上）、深水炸弹（飞出顶边再空心）、绝杀（压哨）。

## 球种

标题页可选下列球种（监狱球在数据里，**当前未开放**）。除燃烧球外，技能文案与游戏内卡片一致（燃烧球卡片原文较玄，下面补了升温规则）。

| 球 | 技能 |
|----|------|
| 经典球 | 别人都靠技能，而我…就很… |
| 忍者球 | 连击 10 / 26 / 40 各获一个影分身；分身只加连击，不计分 |
| 弹力球 | 高弹小号球，穿边朝筐出现 |
| 燃烧球 | 别人卡片上写「什么味道？你闻到了吗？」——连击升温后冒烟 / 起火 / 烈焰额外加分，并可点燃对面篮筐 |
| 冰冻球 | 连击提高冻筐概率；首次冻 4 秒，续冻 3 秒，灌冻筐叠基础分 |
| 冠军球 | 存剩余时间的两成，耗尽后开启双倍冠军时刻（不可用于 1 分钟） |
| 反重力球 | 收集反物质开黑洞；洞时长 20 秒起，场上留存越久洞越短（不低于 10 秒） |
| 玻璃球 | 基础分从 20 起；打铁 −2、擦板 −1、板上端 −3、落地 −4，空心 +4，上限 50 |

肉鸽开局会暂停一次 **开局融合**：从另外三颗随机球里选一颗叠技能（外观和主球物理跟主球走；弹力球作副球时还会缩小半径），也可以不融合。

## 肉鸽商店（当前进度）

正式 5 关，每关目标 200 分。过关结算金币（界面上的「基础得分」20 + 本关最高连击 + 超额分数），然后进商店。商店每次最多上架 **2 个道具 + 2 个饰品**，按稀有度加权（普通 / 稀有 / 史诗 / 传说）。部分饰品有球种条件（例如「提前启动」只要经典球、「安全包装」只要玻璃球）。

道具与饰品已从策划表导入，**目前目录内条目均为启用**（10 个道具、33 个饰品）。完整 id、价格、叠加上限和效果以目录为准：

**[docs/rogue-shop-catalog.md](docs/rogue-shop-catalog.md)**

商店里常见几类（不是完整列表）：

- **过关续命**：重生、热身加时、连击保护、金币护身符
- **进球标签加成**：空心 / 擦板 / 马桶 / 穿针 / 深水 / 幸运 的得分或金币
- **改球店**：过关后和商店一起出现。篮球的全部手感参数做成条，加减一次花钱，下一次更贵。原来的弹跳、重力、摩擦类饰品已下架。
- **其它饰品**：球变小、筐变大、动态篮架概率
- **暂停后手动开**：连击兴奋剂、大力丸、分身术、热火饮料 等

第 5 关打完是通关结算：可以结束本局，或进入无限模式接着打（不再走关卡商店循环）。

## 本地运行

需要 **Node.js**（仓库依赖按 Node 22 编写）和 npm。在仓库根目录：

```bash
npm install
npm run dev
```

`package.json` 里的开发命令是：

```text
vite dev --host 0.0.0.0 --port 8080
```

浏览器打开 **http://127.0.0.1:8080/**（或本机任意网卡的 8080）。这是一页游戏，没有单独的登录或后台。

`startup.sh` 会先探测 `http://127.0.0.1:8080/`：已经有服务就直接退出；否则后台执行 `npm run dev`。脚本里写死了工作目录 `/workspace`，那是沙盒约定——你自己的机器上请在克隆下来的仓库根目录跑 `npm run dev`。

其它脚本（按需）：

| 命令 | 作用 |
|------|------|
| `npm run build` | 生产构建 |
| `npm run typecheck` | TypeScript 检查 |
| `npm run preview` | 预览构建产物 |

最高分、音量和上次模式存在浏览器 `localStorage`，清站点数据会丢纪录。
